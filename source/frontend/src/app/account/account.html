  1. Sign in to Forgejo

    Open Forgejo, choose Sign in, and enter the username and password above. You can change the password there afterwards if you prefer one you can remember — this app will not know about it, and generating a new one here always overrides it.

  2. Clone, then push

    When git asks for a username and password, use exactly the two values above.

    git clone <your repository URL>
cd <folder>
# ...work...
git add -A
git commit -m "my changes"
git push

  3. Type it only once

    Let git remember it for you:

    git config --global credential.helper store

    The next push asks once and then remembers. On Windows use manager instead of store to keep it in the Windows Credential Manager.
