Teacher CLI

Publish an assignment straight from a folder on disk: the tool logs you in, lets you pick a course and enter a title/deadline/instructions, pushes the folder as the starter repo, creates the assignment, and prints the accept link. Download the binary for your platform (no .NET install required).
